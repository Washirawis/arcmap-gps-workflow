# arcmap-gps-workflow
# คู่มือการนำพิกัด GPS เข้าโปรแกรม ArcMap

โปรเจกต์นี้เก็บรวบรวมขั้นตอนและสคริปต์สำหรับการนำเข้าพิกัด GPS เพื่อสร้างชั้นข้อมูล (Shapefile) ใน ArcMap

## ขั้นตอนการใช้งาน (Display XY Data)
1. เตรียมไฟล์ข้อมูลพิกัดเป็นเอกสาร `.csv` 
2. เปิด ArcMap แล้วเลือก **Add Data** เพื่อดึงไฟล์เข้าโปรแกรม
3. คลิกขวาที่ตารางข้อมูล เลือก **Display XY Data...**
   * **X Field:** เลือกค่า Longitude หรือ Easting
   * **Y Field:** เลือกค่า Latitude หรือ Northing
   * **Coordinate System:** เลือกระบบพิกัดให้ตรง เช่น `WGS 1984` หรือ `WGS 1984 UTM Zone 48N`
4. คลิกขวาที่ชั้นข้อมูล Events เลือก **Data -> Export Data...** เพื่อบันทึกเป็น Shapefile ถาวร

---
*บันทึกเพิ่มเติม:* หากต้องการจัดรูปแบบข้อมูลก่อนนำเข้า สามารถใช้สคริปต์ในโฟลเดอร์ `scripts/` ช่วยประมวลผลได้
